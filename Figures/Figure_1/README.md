This folder contains data for figure 1. 
Specifically, it contains four subfolders, for figures 1c, 1d, 1e and 1f. Figures 1a and 1b can be generated from CIF files for TaTe4 and by creating a tetragonal Brillouin zone, respectively. Figure 1g is a zoom in for each of the features of 1g, which means it can be created from 1f subfolder data.
